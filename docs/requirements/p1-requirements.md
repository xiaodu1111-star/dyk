## 0. 一句话定位

P1 让 Personal OS 从「能登录」变成「**每天真的会用**」：交付工作域、SOP 库、生活域三个模块，跑通「记录 → 度量」的第一段闭环。

## 1. 背景

- P0 已交付：登录闭环（后端三接口 + 前端 iOS 26 玻璃主题），代码已推 GitHub（`main`）。
- P1 选这三个模块的理由（沿用总设计第 4 期规划）：
  1. **工作域**是使用频率最高的入口，不先上，系统就没有每天打开的理由；
  2. **SOP 库**是本项目差异化价值——小杜的核心诉求是"沉淀工作流程"，任务是消耗、SOP 是复利；
  3. **生活域**建立节奏感，且是三大通用引擎（指标引擎）的第一次实战，跑通了后面学习/运动/理财域几乎零成本。

## 2. 用户故事（需求主体）

### 2.A 工作域（任务）

| # | 故事 | 验收要点 |
|---|---|---|
| A1 | 我早上打开系统，一眼看到今天的任务 | 首页/工作页有「今日」视图，只列今天该做的 |
| A2 | 我能在 **15 秒内**新增一条任务 | 只有标题必填；标签、预估时长、截止日全部可选 |
| A3 | 做完一件事点一下勾掉 | 状态流转：待办 → 进行中 → 完成（→ 放弃）；勾掉写一条活动流 |
| A4 | 昨天没做完的任务，我能在"逾期"分区看到它们 | 逾期任务留在原日期、红色标记"逾期"，**不自动顺延**（小杜拍板）；重新排期 = 手动改截止时间 |
| A5 | 我能看全部任务列表 | 今日 / 全部 / 逾期三个视图；P1 不做复杂筛选 |
| A6 | 任务能打标签 | 走标签引擎（多态标签，跨域检索的地基） |

**数据**：`work_task` 专表（有状态机，符合总设计的建专表判断规则）。

### 2.B SOP 库（核心差异化）

| # | 故事 | 验收要点 |
|---|---|---|
| B1 | 我能创建 SOP：标题 + 一句话适用场景 + 步骤列表 | 每步：标题必填 + 说明可选；步骤可增删排序 |
| B2 | 我能按步骤执行一个 SOP | 发起一次「执行」，逐步勾，可选记实际用时 |
| B3 | 执行完有记录 | 每次执行落 `work_sop_run`：第几步卡住、总时长 |
| B4 | 我能看到一个 SOP 的执行历史 | 跑过几次、平均多久、常卡在哪步 |
| B5 | 我改一个用过的 SOP，旧版本留底 | 编辑已执行过的 SOP 自动留版本快照，可回看 |
| B6 | 同一件事做了 3 次，系统提醒我沉淀 | 同标题任务出现 ≥3 次 → 首页提示，一键带标题进入创建页 |
| B7 | 常用 SOP 好找 | 按最近使用 + 使用次数排序，支持置顶 |

**数据**：`work_sop` / `work_sop_step` / `work_sop_version` / `work_sop_run` 四张表（总设计 5.x 已有 DDL）。
**B6 弱依赖说明**：提示逻辑放在首页聚合服务里，SOP 模块只提供创建接口——**不阻塞并行开发**。

### 2.C 生活域（习惯打卡 + 快捷记录）

| # | 故事 | 验收要点 |
|---|---|---|
| C1 | 我能自定义习惯（如"23:30 前睡"） | 两种类型：每日打卡型 / 每日计数型 |
| C2 | 我每天点一下就完成打卡 | 计数型点一下 +1；重复点不重复计 |
| C3 | 我能看到连续坚持了多少天 | streak 计算，口径见决策点 ① |
| C4 | 我打个字就能记一笔 | 快捷记录条：输入「跑步 5」→ 匹配已有习惯「跑步」+ 数值 5 → **预填 + 确认**（不是直接落库） |
| C5 | 首页能看到今天打卡状态 | x/y 进度；全绿有成就感反馈 |

**数据**：**不建专表**。习惯 = 指标引擎的一条 `sys_metric_def`，打卡/计数 = `sys_metric_record`。这是总设计「指标可配置」原则的落地：以后加一个新习惯不改表不改代码。

### 2.D 首页升级（真实数据）

- 问候卡保留；
- 领域卡片从占位变真实：**工作卡**（今日任务 x/y）、**生活卡**（打卡 x/y）；
- 学习 / 运动 / 理财三张卡显示「即将上线」（P2/P3 开通）；
- 数据来源：聚合接口 `GET /api/dashboard/home`。

## 3. 非目标（P1 明确不做）

学习域、运动域、理财域页面（P2/P3）· 番茄钟（P2，见决策点 ②）· 日历/甘特视图 · 任务依赖关系 · SOP 富文本与附件 · 统计图表与周报（P4）· 通知提醒 · PWA · 多用户 · 番茄钟以外的计时类功能

## 4. 开放决策点（✅ 2026-10-01 小杜已全部拍板）

| # | 问题 | ✅ 拍板结果 | 备注 |
|---|---|---|---|
| ① | 时间口径 | **自然日 00:00 分界** | `PeriodUtil` 集中实现，预留 04:00 切换位（不实现，只留结构） |
| ② | 是否引入 Redis | **P1 不引入** | 番茄钟整项推迟到 P2；继续内存会话 |
| ③ | 任务逾期策略 | **只标记逾期，不自动顺延** | 逾期任务留在原日期、红色标记，单独"逾期"视图分区；重新排期手动改截止 |
| ④ | 首页是否接真实数据 | **接** | 工作 + 生活两张卡接真实数据，未开通域显示占位 |
